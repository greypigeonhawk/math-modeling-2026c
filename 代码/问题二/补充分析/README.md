# 问题二 补充分析：CP-SAT 复核与鲁棒性

这是问题二“补缺口径”一侧的复算代码，与同目录 `代码/问题二/` 下另一套“资源池分摊”脚本互为对照。

## 结论（补缺口径，熟练度 1.0）

| 规模 | N 派出 | 配套人员 | CP-SAT 完工 |
|---|---|---|---|
| A32+B16（48 架） | 1 车 | 2 人 | 113 min |
| A32+B24（56 架） | 3 车 | 5 人 | 114 min |
| A32+B30（62 架） | 8 车 | 12 人 | 112 min |

跨机型熟练度 0.9 严格执行时：2 车 3 人 / 4 车 6 人 / 10 车 15 人。

## 口径

- 单机关键链不计牵引：A 41 min、B 73 min；计入 10% 机位的牵引与附油后为 51 / 83 min。由 120 min 倒排得 B 机加油须在 47 min 前开工（第三问 80 min 窗口下同一公式给 7 min）。
- 牵引、附油各覆盖 10%（只牵引 8%、只附油 8%、兼需 2%），按 ⌈W/96⌉ 均为 1 辆，M 的 8 辆 Z1、1 辆 Z7 已够。
- 充气并发编组：每侧 ⌈N/10⌉ 辆、3 min 一批，单侧限 10 架。
- 电源、空调 1 车 2 架位；加油、餐食、牵引、附油 1 车 1 架。
- 强度 ρ = 组内工时 /(在岗人数 × 120) ≤ 0.8；极差 15 点只考核主工序。

## 文件

| 文件 | 作用 |
|---|---|
| `q2_check.py` | 给定配置的 CP-SAT 最短完工判定（三档 + M 自有配置） |
| `q2_round_sens.py` | 10% 机位取整口径敏感性：全机队总量 vs 按机型分别（两遍完工一致） |
| `q2_robust.py` | 全工序时长整体抖动 δ = 0/1/2/3 min 的完工，及牵引全覆盖情形 |
| `q2_jitter_margin.py` | 加 1~2 辆 Z2 后能否吸收 δ = 1/2 min 抖动 |

## 复现

```bash
pip install -r requirements.txt
python q2_check.py        # 113 / 114 / 112 min；M 自有配置 93 min
python q2_round_sens.py   # 两种取整口径均为 113 / 114 / 112 min
python q2_robust.py       # δ = 0/1/2/3 → 113/121/128/135 等
python q2_jitter_margin.py
```

## 鲁棒性结论（与第三问对齐）

全工序整体加 δ 后：48 架 113→121→128→135，56 架 114→121→128→135，62 架 112→120→125→130。δ = 1 min 即把 48、56 顶出 120 min，说明 7~8 min 余量只等于一次全线 1 min 级抖动，不构成抗扰能力。加 2 辆 Z2 的留余量版本：97 / 105 / 104 min，可吸收 ±2 min。
