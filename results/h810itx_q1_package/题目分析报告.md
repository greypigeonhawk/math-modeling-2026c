## 2. 子问题拆解与模型合同

### 问题1：M地勤首次保障 A 型机

| 合同项 | 设计 |
|---|---|
| 任务定义 | 固定图1流程下求100分钟最大保障架数；给定120分钟保障156架时，求最少新增人员、车辆；再在允许调整的工序先后关系下重复计算，并优化附录4技能表。 |
| 数据 | M地勤8组人员及Z1—Z9存量；工序单机工时、车辆并行能力和需求规则；多技能折减系数；工序优先及互斥规则。单位统一为分钟、架、人、辆。 |
| 结论类型 | 最大吞吐量、满足需求的增援资源清单、固定与可调流程的能力差异、调整后的技能配置建议。 |
| 模型 | 离散时间资源受限项目调度/混合整数规划。按飞机和工序设置开始时刻、完成变量、人员技能分配和车辆占用，最小化工期或最大化时限内完工数。 |
| 数学定义 | 令 $s_{i,o}$、$c_{i,o}$ 分别为飞机$i$工序$o$的开始和结束时刻，$p_{i,o}$为工时，满足 $c_{i,o}=s_{i,o}+p_{i,o}$；图1的前置边$(o,o')$要求$s_{i,o'}\ge c_{i,o}$。人员/车辆单资源不重叠，车辆并行容量按任务表给定。100分钟目标最大化完成全部必需工序的飞机数。增援按附录8优先级逐级最小化新增车辆，同优先级车辆数最少后，再最小化新增人员；另报告人车总量的非支配备选。技能优化满足每人固定1个第一技能、第二技能≤3、总技能≤5。 |
| 实现 | 建议 Python + OR-Tools CP-SAT 或 MILP 求解器。输入为工序网、资源、技能矩阵和时间窗；输出为逐机逐工序时刻表及资源需求。 |
| 验证 | 独立模拟复核排程；逐项检查资源不超配、工序先后和互斥；对整数比例取整、技能熟练度和目标优先序作敏感性检查。 |
| 风险 | 附录3的牵引和附油比例可能有交集解释差异。主口径按需牵引为10%、其中20%需附油，则两者交集为总机数的2%；总附油需求仍按10%，其余8%为不牵引附油。数量按完整任务总量累计取整，并对批内逐次取整做敏感性复算。 |

### 问题2：N地勤伴随保障

| 合同项 | 设计 |
|---|---|
| 任务定义 | 在120分钟保障32架A机及16、24、30架B机，选择N地勤派出的人车并形成联合模块编组，兼顾工作强度均衡。 |
| 数据 | M/N人员车辆配置；A/B单机工时；N人员对A机熟练度0.9；A、B混编需求；问题1所得首保流程。 |
| 结论类型 | 各机型组合下N方派出资源数量、人员技能和车辆类别、排程、利用率/负荷均衡指标。 |
| 模型 | 与问题1同一资源受限调度模型，扩展为多机型、多地勤资源池与公平性多目标优化。 |
| 数学定义 | 令$y_j$为N地勤派出资源$j$的数量，首先约束全部任务在120分钟内完成。人员负荷$L_j$定义为人员$j$承担工序的实际分钟数，归一化负荷$r_j=L_j/120$；在完成时限可行的方案中，先最小化派出人员与车辆数量，再最小化$\max_j r_j-\min_j r_j$。非本场机型工时按题给熟练度系数折算，第二/第三技能人员分别按0.8/0.4熟练度换算。 |
| 实现 | 在同一 CP-SAT/MILP 调度模型中把M地勤资源固定为可用库存，将N方派出量设为整数决策变量。 |
| 验证 | 检查各工序熟练度和资源归属；用排程仿真确认时间窗；报告各组负荷均值、极差或变异系数，避免只给“均衡”定性判断。 |
| 风险 | 人车是否必须成套出动由“伴随保障”定义与表格填报口径确认；均衡目标权重与资源最少目标的冲突需明确呈现。 |

### 问题3：华盛顿机场45波次再次保障

| 合同项 | 设计 |
|---|---|
| 任务定义 | 对机场正常、甲跑道停用停机坪、乙跑道及地勤失能三种情景，安排各批降落跑道、地勤驰援及保障资源，保证45波次每批96机连续保障。 |
| 数据 | 七跑道A/B停机容量；甲乙丙丁地勤人员车辆；跑道间公路距离与80 km/h速度；每波次12批、每批6A+2B；回航间隔120分钟；批次着陆间隔≥10分钟、批内飞机间隔≥1分钟；单机再次保障≤80分钟；跑道接收18批后休息180分钟。 |
| 结论类型 | 三种情景下可行的跑道分配、跨跑道驰援出发/到达时刻、人车配置、每批机队的逐工序排程和总完工时间/违约情况。 |
| 模型 | 多跑道离散事件调度与带时变资源可用性的混合整数规划；跑道支援关系建模为带移动时长的网络资源流。 |
| 数学定义 | 对批次$b$、跑道$r$设首架着陆时刻$t_b$及指派变量$z_{b,r}\in\{0,1\}$，每批恰选一条跑道。批内8架按至少1分钟间隔，末架着陆时刻为$t_b+7$；批间约束$t_{b+1}-(t_b+7)\ge10$。同批A/B飞机统一跑道并受对应机型容量限制。每机定义末道保障完成时刻$c_i$和起飞时刻$u_i$，满足$u_i\ge c_i$；80分钟窗口为$c_i\le t_i^{land}+80$，再次着陆满足$t_{i,q+1}^{land}\ge u_{i,q}+120$。K时刻仅作为首架首道工序的时间原点。飞机停机位从着陆占用至保障后离位，若等待起飞则占位至起飞。跑道第18批末架着陆后休息180分钟，期间现有人员和车辆不可工作且不接收新批；已停飞机由其他已到场且未休息资源保障，无替代资源时等待。支援人车从驻地出发即被占用，移动时间$d_{r,r\prime}/80\times60$分钟，到达后保障，返程到达才恢复可用。 |
| 实现 | Python + CP-SAT/MILP 建立全局时间索引模型；若全规模模型超时，采用按波次滚动优化并冻结已执行批次，辅以事件驱动仿真核验。 |
| 验证 | 对全部批次复算着陆间隔、停机容量、80分钟窗口、跑道休息和支援到达时刻；通过仿真检查跨跑道资源冲突；报告求解器界或启发式差距。 |
| 风险 | 45波次共4320架。P1关键路径算例显示，未牵引B机再次保障下界为73分钟，被牵引B机为83分钟，题面明确飞机着陆后立即开展再次保障并要求80分钟内完成，故牵引计入时限。被牵引B机的关键路径下界为83分钟，超过时限；但题目没有规定被牵引对象的机型。每批8架的10%为非整数，主模型按跨批累计形成牵引数量，并把牵引对象作为优化变量，优先比较分配给A机或混合机型的可行性。不得据被牵引B机路径单独推断全题无解；若取整规则或对象分配影响可行性，须报告各口径结果。题面未完全说明回到上空至着陆之间等待，主口径将上次起飞后120分钟作为最早可着陆时刻，并对等待量作敏感性复算。情景2中甲地勤仍完好且可移动支援，但甲跑道不可接收停留飞机。 |
