## 2. 独立复核范围

新增 `验证问题3候选.py`，对每个候选重新检查：

- 逐批 8 架、批内至少 1 分钟、相邻批次首机与前批末机至少 10 分钟；
- 每架飞机的牵引、加油、充氧、充氮、餐食、电源、空调前置关系；
- 着陆后 80 分钟完成限制和 A/B 机工时；
- 电源/空调一车一人、最多两架同步配对及每架恰好覆盖一次；
- 跑道/地勤资源峰值、停机位容量、18 批后 180 分钟休息窗；
- 驰援候选的道路距离换算和到达时刻。

三个主候选的复核命令均返回 `PASS`：

```text
python 验证问题3候选.py results/q3_serial_45waves_80.json
python 验证问题3候选.py results/q3_dual_45waves.json
python 验证问题3候选.py results/q3_three_45waves.json
```

## 3. 关键假设与边界

关键假设：第18批完成保障后才开始180分钟休息；首机着陆与K同时；每机保障结束立即起飞；主候选只使用第一技能；电源和空调采用同步配对解释；驰援到达后直接驻留目标跑道。题面没有提供地面转移至其他停机坪的路线，因此甲跑道停机坪失能情景尚未加入落地后转移机制。

机型作业明细参见 q3_serial_45waves.json；该JSON尚未包含官方结果模板所需的逐行车辆类型、人员所属地勤与技能等完整字段，不能视为最终提交附件。

改进候选：在相同 F3/丙地勤及休息假设下，将同跑道批次首机间隔从 100 分钟缩至 80 分钟，完工时刻减少 10200 分钟。双跑道和三跑道候选进一步利用不同跑道的独立资源；它们是构造式候选，不是联合 CP-SAT 全局优化结果。
