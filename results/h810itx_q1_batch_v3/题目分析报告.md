### 问题2：N地勤伴随保障

| 合同项 | 设计 |
|---|---|
| 任务定义 | 在120分钟保障32架A机及16、24、30架B机，选择N地勤派出的人车并形成联合模块编组，兼顾工作强度均衡。 |
| 数据 | M/N人员车辆表；A、B机首次保障工序时长及资源需求；技能矩阵；附录1对“伴随保障”的定义；三种混合机队$(32,n_B)$，$n_B\in\{16,24,30\}$。N方资源进驻后编入M方保障序列，统一调配。 |
| 结论类型 | 每个机队组合下N方按专业组派出的人数、按车型派出的车辆；模块组成及模块内技能分工；120分钟逐机排程；N方派出人员的负荷均衡指标。 |
| 模型 | 多机型、多技能资源受限调度整数规划。派出总人数和车辆数作为并列指标求非支配方案，避免用无依据权重折算“1人”和“1辆车”。 |
| 数学定义 | 对飞机$i$、工序$o$设开始/结束时刻$s_{i,o},c_{i,o}$，并以$a_{i,o,g,s}$表示来源$s\in\{M,N\}$、专业组$g$承担工序$o$的人数。按图1前置边约束时序，按附录表4区分A、B工时与作业；牵引和附油分别按总机数的10%设置，按附录3处理牵引与附油对象的交集，并对整数取整口径做敏感性计算。令$y_g$、$z_v$分别为N方派出组$g$人数、车型$v$车辆数，$N_g,N_v$分别为N方相应专业组人员和车型车辆的原有库存，$0\le y_g\le N_g$、$0\le z_v\le N_v$，并与M方原有资源共同满足人员和车辆容量；Z3、Z4总数分别满足$\lceil(32+n_B)/10\rceil$规则。全部工序须在120分钟内完成。每个保障模块按任务表定义为车辆与所需人员的功能包：Z1/M5、Z2/M6、Z3或Z4/M8、Z5或Z6/M7、Z7/M2、Z8/2名M1、Z9/1名M3+2名M4（航材）或Z9/2名M4（伞勤）；一专多能人员可以跨模块补位，但通过$a_{i,o,g,s}$限制同一人员不能同时执行两个工序。跨机型0.9与第二/第三技能0.8/0.4按乘积作主口径，并对仅施加0.9折减作敏感性比较。定义N方组负荷$L_g^N$为分配给N来源人员的实际人·分钟，$r_g^N=L_g^N/(120y_g)$；仅比较$y_g>0$组。先求派出人数与车辆数的非支配解集，再按附录8优先级打破同一资源总量下的车型平局，最后最小化$\max_g r_g^N-\min_g r_g^N$。 |
| 实现 | 用CP-SAT区间变量表示机型任务、技能选择和前置关系；以来源标识分开记录M/N人员负荷与容量，M方存量固定，N方派出人数/车辆为整数决策变量；针对16、24、30架B机分别求解并导出资源、模块、逐机排程和负荷。 |
| 验证 | 独立复核120分钟期限、工序前置、车型工时、跨技能折减、人员与车辆峰值；报告帕累托非支配性和各N方专业组负荷。 |
| 风险 | M—N机场间没有给出地面转场距离或到达时刻，主模型按伴随力量随B机同步进驻、在K时刻可用；该假设明确依据附录1“随同飞机转场、进驻后编入序列”，不额外虚构路程。技能系数是否相乘需作敏感性比较。官方C_Solution1.xlsx未在附件中找到，按附录9字段重建结果表。 |
